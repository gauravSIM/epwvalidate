1. File shape

  • Plain text, comma-separated. Semicolons do not end lines.
  • 8 header records, in this order, followed by the data records:
#Record keywordContent
1LOCATIONcity, region, country, source, WMO, latitude, longitude, time zone, elevation
2DESIGN CONDITIONSdesign conditions matched by WMO number
3TYPICAL/EXTREME PERIODStypical and extreme periods found by the Weather Converter's heuristic
4GROUND TEMPERATURESmonthly "undisturbed" ground temperatures at N depths
5HOLIDAYS/DAYLIGHT SAVINGleap year flag, daylight saving start and end, holidays
6COMMENTS 1free text
7COMMENTS 2free text
8DATA PERIODSnumber of periods, records per hour, each period's name, start weekday, start and end

2. Header records

2.1 LOCATION

Example: line 1 of the example file.

LOCATION,
   A1, \field city
   \type alpha
   A2, \field State Province Region
   \type alpha
   A3, \field Country
   \type alpha
   A4, \field Source
   \type alpha
   N1, \field WMO
    \note usually a 6 digit field. Used as alpha in EnergyPlus
    \type alpha
   N2 , \field Latitude
       \units deg
       \minimum -90.0
       \maximum +90.0
       \default 0.0
       \note + is North, - is South, degree minutes represented in decimal (i.e. 30 minutes is .5)
       \type real
   N3 , \field Longitude
       \units deg
       \minimum -180.0
       \maximum +180.0
       \default 0.0
       \note - is West, + is East, degree minutes represented in decimal (i.e. 30 minutes is .5)
       \type real
   N4 , \field TimeZone
       \units hr - not on standard units list???
       \minimum -12.0
       \maximum +12.0
       \default 0.0
       \note  Time relative to GMT.
       \type real
   N5 ; \field Elevation
       \units m
       \minimum -1000.0
       \maximum< +9999.9
       \default 0.0
       \type real

The LOCATION record duplicates the information required for the Location object.

  • With only a Run Period object (a weather file), the Location object is not needed.
  • With a Run Period and Design Day objects, the weather file's location is used, and it overrides any Location object.

Example: line 2 of the example file.

DESIGN CONDITIONS,

The design conditions are matched to the location by WMO number (World Meteorological Organization station number). The weather files carry the design conditions from the ASHRAE Handbook of Fundamentals 2009. Design Day definition files exist for all World, Canada and United States design conditions.

2.3 TYPICAL/EXTREME PERIODS

TYPICAL/EXTREME PERIODS,
     N1, \field Number of Typical/Extreme Periods
     A1, \field Typical/Extreme Period 1 Name
     A2, \field Typical/Extreme Period 1 Type
     A3, \field Period 1 Start Day

CSV
Fld,Name,Units,Min,Max,Default,Note
N1,Number of Typical/Extreme Periods,,,,,
A1,Typical/Extreme Period 1 Name,,,,,

The dictionary's note says "repeat (A1-A3) until number of typical periods". The record defines four fields per period (A1–A4).

The Weather Converter finds typical and extreme periods for full-year files with a heuristic method. They are also reported in the Weather Converter's statistics report.

  • The Weather Converter calculates "undisturbed" ground temperatures from a full year of data. The calculation is a heuristic, time-lagged one based on dry bulb temperature and location (Kusuda).
  • Soil properties cannot be calculated from weather observations, so the record is mainly for user information.
  • With the FC construction option, the 0.5 m depth values are used automatically if the user gives no values in Site:GroundTemperature:FcfactorMethod.
  • These temperatures should not be used for building losses: they are too extreme for soil under a conditioned building. They are appropriate for GroundTemperatures:Surface and GroundTemperatures:Deep.
  • For best results, use the Slab or Basement program to calculate monthly ground temperatures.
  • Without those preprocessors, a reasonable default for typical commercial buildings in the USA is 2 °C below the average indoor space temperature.

2.5 HOLIDAYS/DAYLIGHT SAVING

HOLIDAYS/DAYLIGHT SAVING,

2.7 DATA PERIODS

Example: line 8 of the example file.

DATA PERIODS,
     N1, \field Number of Data Periods
     N2, \field Number of Records per hour
     A1, \field Data Period 1 Name/Description
     A2, \field Data Period 1 Start Day of Week
       \type choice
       \key  Sunday
       \key  Monday
       \key  Tuesday
       \key  Wednesday
       \key  Thursday
       \key  Friday
       \key  Saturday
     A3, \field Data Period 1 Start Day
     A4, \field Data Period 1 End Day
     \note repeat above to number of data periods
-- etc to # of periods entered

The same fields as CSV (comma-delimited):

CSV
Fld,Name,Units,Min,Max,Default,Note
N1,Number of Data Periods,,,,,
N2,Number of Records per hour,,,,,
A1,Data Period 1 Name/Description,,,,,
A2,Data Period 1 Start Day of Week,,,,,"choice: Sunday, Monday, Tuesday, Wednesday, Thursday, Friday, Saturday"
A3,Data Period 1 Start Day,,,,,date field
A4,Data Period 1 End Day,,,,,date field
...,etc to # of periods entered,,,,,repeat above to number of data periods
  • A file may contain several data periods. This is not required, and it may be detrimental.
  • A file may contain several records per hour, but the count must match the Number of Time Steps in Hour of the simulation. Interval data gives the exact weather values for each time step, instead of interpolated values.
  • A file may contain several consecutive years. EnergyPlus processes the extra years when the RunPeriod's Number of Years field is used. There is no way to start in a year in the middle of the file.
  • A Run Period may not cross a data-period boundary.

Notes from the dictionary:

  • The initial day of the weather file is checked by EnergyPlus for validity.
  • Each field is checked for "missing". In its place, EnergyPlus substitutes a reasonable value, a calculated value or the last "good" value.
  • Hour 1 is 00:01 to 01:00.
  • Dry bulb and dew point are full numeric fields (23.6), not integers in tenths.
  • Station pressure limits come from the standard barometric pressure for all elevations of the world.
  • Radiation and illuminance values are amounts received during the number of minutes before the time indicated.
  • Illuminance is the average in hundreds of lux. Zenith luminance is the average in tens of Cd/m2.
  • Wind direction: North = 0.0, East = 90.0, South = 180.0, West = 270.0. If calm, the direction is zero.
  • Total sky cover: 1 means 1/10 covered and 10 means total coverage.
  • Ceiling height: 77777 = unlimited ceiling height, 88888 = cirroform ceiling.
  • Precipitable water is not rain. It is not used because its reporting is unreliable.
  • The field descriptions are taken from the IWEC manual.

4. Horizontal infrared radiation when missing

When N12 is missing, it is calculated from the Opaque Sky Cover field (Walton 1983; Clark & Allen 1978):

Horizontal_IR = ε · σ · T_drybulb⁴        [W/m²], σ = 5.6697e-8 W/m²-K⁴, T_drybulb in K
ε = (0.787 + 0.764 · ln(T_dewpoint / 273)) · (1 + 0.0224 N − 0.0035 N² + 0.00028 N³)
T_dewpoint in K, N = opaque sky cover in tenths

Example: clear sky (N = 0), T_drybulb = 273 + 20 = 293 K, T_dewpoint = 273 + 10 = 283 K: ε = 0.787 + 0.764 × 0.036 = 0.815, and Horizontal_IR = 0.815 × 5.6697e-8 × 293⁴ = 340.6 W/m².

References:

  • Walton, G. N. 1983. Thermal Analysis Research Program Reference Manual. NBSSIR 83-2655. National Bureau of Standards, p. 21.
  • Clark, G. and C. Allen. "The Estimation of Atmospheric Radiation for Clear and Cloudy Skies." Proceedings 2nd National Passive Solar Conference (AS/ISES), 1978, pp. 675–678.

Present Weather Codes (N27)

  • They follow the TMY2 conventions. The field may look numeric, but it is a text field of 9 single digits.
  • Formats that do not follow this convention (for example TMY) are converted to it as far as possible by the Weather Converter.
  • The most important columns are the ones for liquid precipitation, when the building surfaces would be wet.
  • EnergyPlus uses Snow Depth, not these codes, to decide whether snow is on the ground.

Liquid Precipitation Depth (N33)

  • It is the liquid precipitation (mm) observed at the time indicated, over the period given in Liquid Precipitation Quantity (N34).
  • If N33 is not missing, it is used and overrides the rain indicator (IsRain): rain is set when the hourly liquid precipitation is no less than 0.8 mm.
  • If the rain indicator shows rain and N33 is missing or zero, N33 is set to 2.0 mm.

Snow Depth (N30) tells EnergyPlus when snow is on the ground, which can change ground reflectance.
